# # Политика безопасности BitOS

## Поддерживаемые версии

В настоящее время безопасность и исправление критических ошибок поддерживаются только для текущей стабильной ветки проекта.

| Версия | Поддержка безопасности |
| ------- | ----------------------- |
| Текущая | Поддерживается          |
| < Текущей | Не поддерживается       |

## Сообщение об уязвимостях

Если вы обнаружили критическую уязвимость в архитектуре ядра, уязвимость переполнения буфера ввода или баг, приводящий к аварийному завершению работы процессора (Triple Fault):

1. Пожалуйста, не создавайте публичное обсуждение в разделе Issues.
2. Отправьте подробное описание проблемы, шаги для ее воспроизведения на электронную почту владельца репозитория. (sussyback99@gmail.com)

В сообщении укажите, требуется ли упоминание вашего авторства при публикации исправления. Ответ с подтверждением фиксации уязвимости будет направлен вам в течение пару дней.
