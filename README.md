# BitOS (v1.1)

Минималистичная, независимая 32-битная графическая операционная система со встроенной консолью, написанная с нуля на ассемблере NASM и C++.

Проект демонстрирует переход процессора в защищенный режим, прямую работу с видеопамятью VGA, опрос аппаратных портов клавиатуры и собственный парсер команд без использования стандартных библиотек (stdlib) или готовых ОС.

---

## Особенности проекта

* **Собственный MBR-загрузчик (boot.asm)**: Работает в 16-битном реальном режиме, настраивает сегменты, считывает сектора ядра с диска через BIOS (int 0x13), переключает видеорежим и безопасно переводит процессор в 32-битный защищенный режим (Protected Mode).
* **Графический движок VGA 320x200**: Прямая запись пикселей в память по базовому адресу 0xA0000. Полностью кастомный интерфейс консоли и попиксельный рендеринг шрифта (символы отрисовываются геометрическими примитивами).
* **Стабильный опрос клавиатуры (Polling)**: Безопасное чтение скан-кодов из порта 0x60 с предварительной проверкой статус-порта контроллера 0x64, что предотвращает Triple Fault и ложные дублирования нажатий.
* **Кастомный парсер команд**: Встроенный командный интерпретатор, поддерживающий вывод текста на экран через синтаксис STDOUT.WRITE "TEXT".
* **Автоматизированная сборка**: Python-скрипт для быстрой компиляции всех модулей и склейки их в финальный сырой образ диска.

---

## Структура файлов

 * boot.asm — 16-битный загрузчик, инициализация GDT, переход в PM и загрузка ядра.
 * kernel.cpp — Графический интерфейс, движок отрисовки шрифта, обработчик клавиатуры и логика консоли.
 * build.py — Кросплатформенный скрипт автоматической сборки ОС.

## Сборка и запуск

### Требования
Для сборки и тестирования проекта вам понадобятся:
1. NASM (ассемблер)
2. GCC / G++ (с поддержкой таргета под i386)
3. Python 3 (для запуска скрипта сборки)
4. QEMU (или любой другой эмулятор для запуска)

### 1. Компиляция проекта
Запустите скрипт сборки. Он скомпилирует ассемблерный код, C++ ядро и объединит их в готовый образ диска:
```bash
python build.py
```
После успешного выполнения в корневой директории появится файл bitos.bin.

### 2. Запуск в эмуляторе
Для тестирования операционной системы в QEMU выполните следующую команду:
```bash
qemu-system-i386 -drive format=raw,file=bitos.bin
```

## Использование консоли

После загрузки системы перед вами откроется графический интерфейс BitOS Console. 
Вы можете вводить текст с клавиатуры (поддерживается регистр букв и клавиша Backspace).

Чтобы вывести сообщение на экран, введите:
```text
STDOUT.WRITE "HELLO WORLD"
```
После нажатия Enter текст будет обработан внутренним парсером и отобразится в логе консоли.
